# NeuroVue Support

NeuroVue is a viewer for neuroimaging data on macOS, Windows, Linux, iPhone and
iPad. It is a research tool and is not intended for clinical diagnosis.

## Get help

Report a problem or ask a question at
[github.com/cdrake/neurovue/issues](https://github.com/cdrake/neurovue/issues).
Include your device, OS version, NeuroVue version (About NeuroVue) and the steps
that cause the problem. Don't attach identifiable patient data.

## Common questions

- **Which files open?** NIfTI (`.nii`, `.nii.gz`), NeuroVue bundles
  (`.nvbundle`), NiiVue documents (`.nvd`) and common mesh formats.
- **How do I get files onto an iPad?** Use Files, AirDrop, or Send to iPad from
  NeuroVue on a Mac. On the iPad, choose Receive from a Mac first.
- **Send to iPad can't find my device.** Both devices must be on the same
  network, and NeuroVue needs Local Network access (Settings → Privacy &
  Security → Local Network).
